# Bangkok Nearby

Personal map of ~200 fun/unusual Bangkok spots (themed cafés, speakeasies, house/techno clubs, rooftops, weird museums, markets, activities) collected from creator, Reddit and city-guide sources in Oct 2026.

- `index.html` – the app (Leaflet + CARTO tiles, GPS, category filters, near-me list, surprise button)
- `data.js` / `places.json` – the place data. Edit `places.json`, then regenerate `data.js`.
- `bangkok-nearby.kml` – same pins for Google My Maps import.

## Your own data
Visited places (with date, stars, notes) and places you add yourself are stored on your phone only.
Use Menu → "Download backup" now and then. Restore with Menu → "Restore from backup file".
To add your own places to the main guide permanently, use Menu → "Copy my added places as text" and paste it to Claude.
